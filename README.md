REFERÊNCIAS:

LINK 2 — CHECKOUT:

https://certificadomeidigital.com.br/checkout.html?cnpj=68026357000182&nome=WELLINGTON+DA+SILVA

- print completo da página principal;

- print completo da página de pagamento;

- arquivo HTML da página de pagamento.

Analise profundamente todas as referências antes de começar.

NÃO UTILIZAR:

- nome Gov.br;

- texto Governo Federal;

Central MEI Digital

INTEGRAÇÃO PIX E SUPABASE

==================================================

Usar Supabase.

Criar Edge Function:

create-pix-payment

Responsabilidades:

- validar os dados;

- criar o cliente;

- criar o pedido;

- usar idempotência;

- chamar o provedor de pagamento;

- retornar QR Code;

- retornar código copia e cola;

- retornar transaction_id;

- retornar data de expiração;

- nunca expor credenciais no frontend.

Criar Edge Function:

check-payment-status

Responsabilidades:

- receber o identificador do pedido;

- consultar o status;

- retornar pending, paid, expired, cancelled ou failed.

Criar Edge Function:

payment-webhook

Responsabilidades:

- receber notificação do provedor;

- validar assinatura do webhook;

- impedir eventos duplicados;

- atualizar o pedido;

- salvar o evento recebido;

- marcar como pago somente após confirmação oficial.

Não invente endpoints do provedor.

Deixe a integração preparada para receber posteriormente a documentação de:

- UniãoPay;

- Mercado Pago;

- Asaas;

- Efí;

- Pagar.me.
